# الشغل الباقي على الفرونت: سديل وبتول

**الوضع هلأ (`main`):**
- صفحة Home تبع بتول صارت جوّا Next.js.
- الـ Explorer تبع سديل شغّال مع الباك إند، وصار بنفس خط وألوان الـ Home.
- الشعار معمول بالكود (HTML/SVG).
- التلسكوب الصغير ثابت جنب الأرض، والكبير بيظهر لما نوصل للقسم التاني.

**قبل أي شي، كل وحدة تعمل:**
```bash
git pull origin main
cd frontend && npm install
```
وكل شغل جديد على فرع خاص فيها (`feat/...`)، ولما تخلص بتفتح Pull Request على `main`.

أولويات المهام: 🔴 قبل الديمو، 🟡 بتقوّي التحكيم، 🟢 إذا ضل وقت.

## سديل: الـ Explorer

### 🔴 S1. مراجعة التعديلات على كودك
عملنا تعديلات على ملفاتك، فراجعيهم وخبّرينا إذا في شي مش عاجبك:
- [ ] `lib/observations.ts`: إذا الـ band إله زيارة وحدة بس، بينختاروا **كل صورها** (Vesta صار يعمل blink لحاله).
- [ ] `lib/api.ts`: `waitForImage()` بدل `img.decode()`، لأنه decode كان بيعلّق إذا التاب مخفي.
- [ ] `components/explorer.tsx`: رابط المشاركة صار يعلّم بطاقة الهدف لحاله.
- [ ] `app/globals.css`: الألوان والخطوط صارت متل الـ Home، والشعار صار مشترك.
- [ ] شغّلي `npm run test` (لازم 9 من 9) و `npm run build`.

### 🔴 S2. تجربة البيانات الحقيقية
لحد هلأ اشتغلتي على الـ mock. بالـ real mode السلوك مختلف (التفاصيل بـ `api-contract.md`، قسم "Real data mode"):
- [ ] جنى بتشغّل الباك إند بـ `DATA_SOURCE=real`، وإنتِ جرّبي إحداثيات Barnard's Star لسنة 2026: `ra=269.4463&dec=4.76798`
- [ ] تأكدي من:
  - 300+ نتيجة على 4 زيارات: القائمة بتضل مرتبة وسهلة؟
  - كل صورة بتاخد 5–30 ثانية أول مرة: الـ loading واضح؟
  - `wavelength_um` بنتايج البحث **null**: القائمة بتعرض شي منطقي بدل الرقم؟
  - تحذير الطول الموجي بيطلع لما الصور مختلفة؟
  - بطاقة الـ "LIVE ARCHIVE" بتطلع بدل "MOCK DATA"؟

### 🔴 S3. وضع القصص (Story mode)
أقوى إضافة لمعيار **Storytelling**: 3 جولات قصيرة خطوة بخطوة، كل وحدة بتختار الهدف والصور لحالها وبتشرح:
- [ ] **"Something moved"**: Vesta، الكويكب بيقفز بين الصور.
- [ ] **"Something changed"**: Mira، نفس المكان بس السطوع بيقل.
- [ ] **"Why can't we see it move?"**: Barnard's Star، بيتحرك أقل من بكسل، وهاد حد دقة SPHEREx (6″ لكل بكسل).
- [ ] *(بتنفع لـ Planet X)* جملة بالآخر: "A real Planet X would be fainter and slower than all of these."
- [ ] نص قصير ودقيق علمياً، **بدون "اكتشفنا"**. خلّي يزن يراجعه.

### 🟡 S4. خريطة سماء لاختيار المكان
بدل كتابة RA/Dec كأرقام: خريطة سماء تفاعلية (**Aladin Lite** من CDS، مجانية ومعتمدة بالفلك)، والمستخدم بيكبس على أي نقطة.
- [ ] تنحمّل بس بصفحة `/explore`، وبتعبّي RA/Dec وبتعمل بحث.
- [ ] **مهم:** اكتبي مصدرها بالصفحة (CDS / Aladin).

### 🟡 S5. أدوات مقارنة
- [ ] **مسطرة مقياس** على الصورة (مثلاً 60″ = 10 بكسل)، عشان المستخدم يفهم حجم الحركة.
- [ ] **سلايدر swipe:** صورتين جنب بعض، وخط بيتحرك بيناتهم.

### 🟢 S6. إضافات
- [ ] تصدير الـ blink كـ GIF للمشاركة.
- [ ] شريط زمني: المسافة بين الصور بتمثّل الوقت الحقيقي.
- [ ] واجهة بالعربي (من اليمين لليسار)، وهاد بيقوّي معيار Global connection.
